# هوية تطبيق LorkERP

أيقونة مرسومة بالكود (`tool/gen_erp_icons.py`): دفتر حسابات فيه أعمدة صاعدة، بالأبيض فوق تدرج أخضر. هذا يميّزها على الهاتف عن أيقونة «المدقق».

لإعادة توليد كل الملفات بعد أي تعديل على الرسم أو الألوان:

```
python3 tool/gen_erp_icons.py
```

يكتب السكربت:

- أيقونات Android في `android/app/src/main/res/mipmap-*`، بكل الكثافات، وتشمل الأيقونة التكيفية مع الشكل الأحادي.
- `drawable/ic_launcher_background.xml`.
- `assets/brand/logo.png` (الشعار داخل التطبيق).
- الملفات أدناه.

## الملفات

| الملف | الاستخدام |
|---|---|
| `icon-1024.png` | الأيقونة الكاملة (مربع بزوايا مستديرة، خلفية شفافة) |
| `play-store-512.png` | أيقونة المتجر (بلا شفافية) |
| `logo-mark-1024.png` | الرسم وحده بالأخضر الداكن، بخلفية شفافة |
| `logo-monochrome-1024.png` | الرسم بالأبيض، وهو أيضًا أيقونة Android 13 الملوّنة بثيم الهاتف |
| `background-gradient-512.png` | التدرج وحده |

## الألوان

| الاسم | HEX | الاستخدام |
|---|---|---|
| أخضر داكن | `#0B4D3C` | بداية التدرج (أسفل اليسار) |
| أخضر فاتح | `#2F9A74` | نهاية التدرج (أعلى اليمين) |

ألوان الواجهة في `lib/ui/erp_theme.dart`، وهي نفسها في «المدقق».

## الخط

Tajawal بأربعة أوزان (400، 500، 700، 800)، مضمّن في `assets/fonts`.
